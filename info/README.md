## Версии документации (ориентир)

- **44-ФЗ:** альбом ТФФ **16.2** / схемы **16.2.6.9** (итерация 1)
- **223-ФЗ:** альбом ТФФ **16.2** / схемы **16.2**
- REST 223: версия API **1.3**

## С чего начать

1. Прочитать [HUMAN_EIS_OVERVIEW.md](./HUMAN_EIS_OVERVIEW.md).
2. Зафиксировать закон (44 / 223 / оба) и профиль доступа (MIS, РИС, ВСРЗ…).
3. Следовать [WORK_INSTRUCTIONS.md](./WORK_INSTRUCTIONS.md).
4. При реализации отдавать агенту [AGENT_EIS_INTEGRATION.md](./AGENT_EIS_INTEGRATION.md) и сверяться с [ANALYSIS.md](./ANALYSIS.md).

Секреты (пароли, ключи, сертификаты) в git не класть.
